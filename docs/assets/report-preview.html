METHOD / LIMITS / PROVENANCE

A report you can trace.

Bounded collection

Selected settings and metadata are collected from a locally registered target. File contents containing confidential data, password hashes and private keys are excluded. Application authorization, external TLS, cloud policy and recovery tests need separate evidence.

Standards alignment

ISO mappings are original educational suggestions. Confirm control applicability, the Statement of Applicability and organizational requirements with a qualified reviewer. Include the 2024 context amendment in the real ISMS scope review.

Evidence integrity

Snapshot identifiers use SHA-256. The local event chain detects accidental modification, but a workspace administrator can rewrite it. Independent custody or signed external evidence is needed for stronger assurance.

Time and ownership

Findings describe the target at collection time. A container or WSL guest cannot establish every host control. Assign owners, document accepted risk and retest changes before closing findings.
