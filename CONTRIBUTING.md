# Contributing

Use Python 3.11+ and `uv sync --frozen`. Run Ruff and the regression suite before proposing changes. Keep target access read-only by default and preserve the ten-step confidentiality subject.

Add only bounded observations or explicitly defined remediation actions. A new action must include exact diffs, applicability checks, stale-state detection, backup/rollback and meaningful failure tests. Never add a model-controlled shell, URL fetch or arbitrary file-content read.

Report template changes must preserve escaping, offline operation, correct evidence states and print readability. Check desktop and mobile widths. Do not put implementation details into the report unless they help the system owner assess the evidence.

Generated previews must be labeled synthetic. Actual audit evidence belongs in the ignored private workspace. Use `scripts/check_repository.py` before publication.
